# Reference feature inventory

The public `https://www.blueman.site/` experience currently presents a loading gate titled “Blue man” with progress text “Initializing D-Bot…” and “Connecting market data…”. The page does not expose an inspectable post-login workspace in the public DOM. Earlier inspection showed its login control delegates to Deriv’s dashboard login rather than exposing Blueman’s private screens.

Therefore, feature parity after Deriv login cannot be inferred reliably from the public site alone. Ernest should implement only features supported by the authenticated Deriv APIs and any private product requirements or screenshots the user supplies, rather than inventing private screens or account data.

The user supplied a post-login screenshot defining the visible feature map: Dashboard, Bot Builder, Free Bots, Strategies, Analysis Tools, D-Trader, Auto Trader, Bulk Trader, Signals, Matches, Speedbot, Charts, Copy Trading, Reports, currency/account controls, a bottom execution bar, and a risk disclosure. Ernest now exposes these areas in an authenticated workspace route with real public market streaming, live account synchronization, local strategy/bot drafts, contract preview safeguards, and explicit provider-dependent states.

Local preview verification with a temporary non-sensitive UI token confirmed the `/workspace` shell renders the top account controls, all screenshot-defined navigation modules, dashboard quick actions, live market panel, reports links, risk disclosure, bottom execution bar, and Bot Builder editor. With the fake token, the account panel correctly falls back to “No accounts” rather than fabricating balances; no real credential was used in the preview.

Authenticated inspection of Blueman at `?account=USD` revealed the concrete D-Bot workspace. The top bar includes a Reports link, display-currency selector, account balance, announcements, and tab arrangement. The module bar contains Dashboard, Bot Builder, Free Bots, Strategies, Analysistools, D-Trader, Auto Trader, Bulk Trader, Signals, Matches, Speedbot, Charts, and Copy Trading.

The Dashboard/D-Bot surface includes My computer, Free bots, Bot editor, welcome guides and FAQs, a Risk Disclaimer, a run panel with Summary, Transactions, Journal, Reset, and performance metrics, an AI Scanner, Quick strategy, a searchable Blocks menu, and block groups for Analysis Logics, Trade parameters, Purchase conditions, optional Sell conditions, Restart trading conditions, Analysis, Utility, Virtual Hook Switcher, Custom Notification, Binarytools, Contract modifiers, and Barrier Settings. The bottom toolbar exposes Run, Slow execution, language, timestamp, theme, and fullscreen controls.

The authenticated Free Bots module loads a catalog of named bot templates, each with a `Load Bot` action. Observed examples include recovery, over/under, digit-switcher, speed-match, and destroyer-style templates. It reuses the shared D-Bot run panel, block menu, toolbar, risk disclaimer, and execution controls rather than opening an unrelated product shell.

The authenticated Strategies module presents downloadable or viewable strategy guides, including beginner and trade-type PDFs, inside the same D-Bot shell. The selected guide opens an embedded document viewer with thumbnails, page navigation, zoom, fit-to-page, rotate, annotate, save/download, print, and more-actions controls. The run panel and bot configuration surface remain available alongside the guide.

The authenticated D-Trader tab mounts a dedicated Deriv trading surface inside the central workspace, initially showing “DTRADER — Plan the trade. Let the price come to you.” while it loads. It retains the shared Blueman header, risk disclosure, bot run panel, AI Scanner, block menu, toolbar, and execution bar around the provider-backed trading surface.

The authenticated Charts tab renders a live market chart for a selected symbol such as Volatility 100 (1s) Index, with a chart type selector, live quote/change, trade-type education link, growth-rate choices, stake currency and amount, take-profit fields, and a transaction panel with Download and View Detail actions. The chart is integrated with the shared bot/run panel and execution controls.

The authenticated Copy Trading tab currently shows an account-scoped activity view with a Download control, Filters control, USD-account notice, and date/time row. It reuses the same market chart and trade configuration surface while providing an empty-state history panel when no copy-trading records are available. This indicates Copy Trading is a report/position surface in this account state rather than a static marketing card.
